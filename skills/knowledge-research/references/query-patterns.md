# 查询模式

| 任务类型 | 首选查询 | 补充查询 |
| --- | --- | --- |
| 事实核对 | 主体 + 属性 + 时间 | 同义词、简称、旧称 |
| 流程说明 | 流程名 + 步骤 | 角色、审批节点、异常处理 |
| 对比分析 | 两个对象名 | 各自指标、口径说明 |
| 制度条款 | 制度名 + 条款关键词 | 适用范围、生效日期、修订记录 |

## 原则

- 一次检索只表达一个意图，避免把多个问题塞进同一句。
- 先用短而具体的名词短语，再按命中情况补充限定词。
- 中文长句可拆分；数字、编号、专有名词保持原样。
- 检索结果为空时，先换同义词或上位词，不要立刻扩大知识库范围。
